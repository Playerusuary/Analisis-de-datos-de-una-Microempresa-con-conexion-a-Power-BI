Base de datos

Descarga el archivo la-lonja-del-vecino.db con todos los registros de ventas, inventario y compras actualizados al último día con actividad. Úsalo para conectarlo directamente a Power BI Desktop.

Conectar con Power BI

Sigue estos pasos para conectar el archivo la-lonja-del-vecino.db a Power BI Desktop y visualizar los datos del negocio. Solo necesitas hacer la configuración una vez; después basta con hacer clic en Actualizar cada vez que quieras ver datos nuevos.

1

Descarga e instala el driver ODBC para SQLite

Ve a sqliteodbc.com y descarga el instalador sqliteodbc.exe (versión de 64 bits si tu Windows es de 64 bits). Ejecuta el instalador y acepta las opciones por defecto. No requiere reiniciar.

2

Guarda el archivo de base de datos

Usa el botón Descargar base de datos y guarda el archivo la-lonja-del-vecino.db en una carpeta fija de tu computadora, por ejemplo: C:\PowerBI\la-lonja-del-vecino.db Recuerda esa ruta — la necesitarás en el paso 4.

3

Abre Power BI Desktop y selecciona la fuente de datos

En la barra superior ve a Inicio → Obtener datos → Más… En el buscador escribe ODBC, selecciónalo y haz clic en Conectar.

4

Configura la cadena de conexión

En el menú desplegable elige SQLite3 Datasource. Si no aparece, selecciona (Ninguno) y en Opciones avanzadas → Cadena de conexión escribe exactamente: Driver=SQLite3 ODBC Driver;Database=C:\PowerBI\la-lonja-del-vecino.db Cambia la ruta si guardaste el archivo en otro lugar. Haz clic en Aceptar.

5

Selecciona las tablas que necesitas

Power BI mostrará el Navegador con todas las tablas disponibles: ventas, detalle_ventas, productos, inventario_compras, almacen_stock, categorias. Marca las que vayas a usar en tus reportes y haz clic en Cargar (o Transformar datos si quieres revisar antes con Power Query).

6

Actualiza los datos cuando quieras

Cada vez que descargues una versión nueva de la-lonja-del-vecino.db y la guardes en la misma ruta, basta con abrir el reporte en Power BI Desktop y presionar Inicio → Actualizar para que todos los gráficos reflejen los datos más recientes.

Importante: el archivo la-lonja-del-vecino.db debe permanecer siempre en la misma ruta que configuraste. Si lo mueves o renombras, Power BI perderá la conexión y tendrás que actualizar la cadena de conexión en Inicio → Transformar datos → Configuración del origen de datos.

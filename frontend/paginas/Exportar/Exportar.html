Base de datos

Descarga el archivo logistica.db con todos los datos actuales del sistema listos para conectar con Power BI.

Conectar con Power BI

Puedes conectar Power BI directamente al archivo logistica.db para obtener reportes en tiempo real cada vez que abras o actualices el reporte.

1

Descarga el conector ODBC para SQLite

Instala el driver SQLite ODBC Driver desde sqliteodbc.com. Es gratuito y compatible con Windows.

2

Abre Power BI Desktop

Ve a Inicio → Obtener datos → ODBC. En el menú desplegable selecciona el driver de SQLite que instalaste.

3

Apunta al archivo logistica.db

En la cadena de conexión escribe la ruta completa al archivo, por ejemplo: Database=C:\ruta\base\logistica.db

4

Selecciona las tablas

Power BI mostrará todas las tablas disponibles. Selecciona las que necesites — inventario, ventas, órdenes — y haz clic en Cargar.

5

Actualización en tiempo real

Cada vez que abras el reporte en Power BI Desktop haz clic en Actualizar para traer los datos más recientes del sistema. Para automatizarlo, configura una Actualización programada desde Power BI Service.

El archivo logistica.db debe estar accesible desde la misma computadora donde corre Power BI. Si lo mueves de ubicación, deberás actualizar la ruta de conexión.
